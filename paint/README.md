# Kasumi Paint

AzPainter2 の描き味を目標にした、軽量なお絵描きソフト（Windows ネイティブ / Tauri）。

## 機能
- 筆圧対応ブラシエンジン（筆圧→太さ/濃さ、筆圧カーブ、硬さ、間隔、手ぶれ補正、濃度と流量の分離）
- プリセット: ペン / 鉛筆 / 筆 / エアブラシ / 水彩 / 消しゴム（設定は自動記憶）
- ペンのテールスイッチで消しゴム、Shift+クリックで直線
- レイヤー（合成モード12種、不透明度、透明部分保護、結合、複製、左右反転）
- 塗りつぶし（許容誤差、領域拡張、全レイヤー参照）、スポイト
- 表示の拡大縮小・回転・左右反転、高DPI対応、タッチの2本指操作
- 取り消し/やり直し（100段階）、自動保存と復元
- 保存: `.kasumi`（レイヤー付き）、PNG 書き出し、画像読み込み
- フローティングパレット（ドラッグで移動、ダブルクリックで折りたたみ、Tabで全部隠す、位置は記憶）
- ダーク/ライトテーマ

## ショートカット
| キー | 動作 |
|---|---|
| B / E / G / I / H | ブラシ / 消しゴム / 塗りつぶし / スポイト / 手のひら |
| 1〜6 | ブラシプリセット |
| [ / ] | ブラシサイズ |
| X | 描画色と背景色の入れ替え |
| Space+ドラッグ / 中ボタン | スクロール |
| R+ドラッグ, Ctrl+Shift+ドラッグ, Shift+ホイール | 表示の回転 |
| ホイール, + / - | 拡大縮小 |
| Alt | 一時スポイト |
| M | 左右反転表示 |
| Tab | パレットを全部隠す/戻す |
| Ctrl+Z / Ctrl+Y | 取り消し / やり直し |
| Ctrl+N / O / S / Shift+S | 新規 / 開く / 保存 / PNG書き出し |
| Ctrl+Shift+N, Ctrl+E, Delete | レイヤー追加 / 下に結合 / 消去 |

## 開発
```sh
npm install
npm run dev          # ブラウザで確認 (http://localhost:1420)
npx tauri dev        # ネイティブウィンドウで起動（Rust が必要）
npx tauri build      # インストーラ作成
```
Windows 用インストーラは GitHub Actions（`Kasumi Paint (Windows build)`）でも自動生成され、Artifacts からダウンロードできます。
